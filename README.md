# toolsmith

A command-line toolkit for developers, built with Node.js.

## Usage

Run it straight from the repository:

```sh
node bin/toolsmith.js
```

Or make the `toolsmith` command available globally from your local checkout:

```sh
npm link
toolsmith
```

Both print:

```
toolsmith v0.1.0
```
